# CAR35 畫面級對照（AutoRepairOS 還缺什麼）

> 來源：實際操作 CAR35 的畫面截圖 + `Data35.mdb` 逐欄非空筆數
> 資料盤點可重跑：`python scripts/analyze_car35_data.py`
> 功能層對照見 `CAR35_COMPARISON.md`；本檔是**畫面/欄位層**。

「有欄位」與「有值」是兩件事。下表每個欄位都附實測非空筆數，
筆數為 0 或極低者標明 —— 那些不需要為它改 schema。

---

## 一、主選單結構（6 個）

```
1.基本資料   客戶/車籍/廠商/零件/員工/保險公司/銀行/其他資料處理
2.日常作業   估價維修單登錄、進貨單登錄、應收款沖銷、應付款沖銷、
             常用分錄設定、收入/支出費用登錄、應收票據登錄、應付票據登錄
3.報表       客戶、廠商、出險、車輛維修記錄、維修人員記錄、
             當日維修記錄、零件庫存、其他明細表、其他報表
4.工具箱     關於、密碼設定、帳冊重整、環境參數設定、字庫速查、
             設定印表機、變更使用者、資料截取、資料查驗
5.功能鍵     首筆/上筆/下筆/末筆/集錦查詢/新增/刪除/儲存/編製報表/列印標籤/關閉
```

### 不常用 → 往後排（有使用頻率為證）

見 `CAR35_USAGE_FREQUENCY.md`。以下項目**不要**排在前面：

| 項目 | 證據 | 處置 |
|---|---|---|
| 收入／支出費用登錄 | 3,390 筆全部在 1999–2003 年，**近 10 年 0 筆** | 資料已遷，不做新畫面；導覽移到管理區 |
| 車輛定檢排程 | 每年 140–310 筆（近 3 年佔 3.3%） | 已有頁面，不優先強化 |
| 應付帳款／應付票據 | `Firm Pay`、`Check Out` **空表** | 全新功能，不是移植 |
| 零件車種／庫位／來往廠商 | 19 / 10 / 34 筆（0.1–0.3%） | 不要做 |
| 客戶的應收帳款科目／票據科目 | **0 / 0 / 1 筆** | 不要做 |
| Bank 的帳號／開戶日／電話／聯絡人 | **全部 0 筆** | 銀行只需 code + name |

反過來，**近年唯一在成長的是車輛投保**（2024 年 367 筆，超過任一完整年度），
排在定檢與其他加值功能之前。
